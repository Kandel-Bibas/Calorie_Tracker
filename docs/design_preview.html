Calorie Tracker — Branding Design System

Applying minimalist high-contrast vector design principles learned from the Wardrobe app.

Lessons Learned from Wardrobe App Style

  • Vector Simplicity over 3D Renderings: Standard 3D claymorphic app icons with physical cards in them create double borders and render poorly at small device sizes. We adopt a clean flat/shadowed white vector glyph in the center.
  • Glyph Drop Shadows for Depth: The vector icon glyph is elevated with a soft drop shadow (blurred shadow) to separate it from the vibrant color gradient background.
  • Consistent Splash Screen Setup: The splash screen uses the same simplified white transparent logo glyph centered on a solid adaptive background (vibrant blue in wardrobe, warm orange/deep charcoal for calorie tracker).
